# VO2max / MPK Report: отчет по фазам 5-6

Дата: 2026-04-30

Этот документ фиксирует реализацию графиков, сравнения тестов, ручных порогов, лактата и базовых зон.

## Phase 5. Графики и сравнение тестов

Добавлено backend-ядро для визуальной интерпретации тестов:

- `ChartService`;
- подготовка данных для графика ЧСС;
- подготовка данных для графика вентиляции;
- подготовка данных для графика VO2;
- подготовка данных для графика лактата;
- сравнение нескольких тестов одного клиента;
- легенда по датам тестов;
- маркеры порогов на графиках;
- связь строки таблицы с точкой на графике через `item_id`.

Добавлено в API:

- `GET /clients/{client_id}/measurements/{measurement_id}/charts`.

Добавлено в frontend:

- четыре SVG-графика без внешних библиотек;
- отображение нескольких серий при наличии нескольких тестов клиента;
- подсветка выбранной строки на графиках;
- вертикальные маркеры порогов.

## Phase 6. Пороги, лактат и зоны

Добавлено ручное назначение физиологических точек:

- МАМ;
- АэП;
- АнП;
- ДО2;
- МПК.

Добавлено:

- `ThresholdService`;
- хранение порогов как отдельных сущностей;
- audit trail для назначения порога;
- привязка порога к выбранной строке измерения;
- запись `sport_parameter` в строку таблицы;
- ввод и редактирование лактата через таблицу;
- расчет базовых зон по АэП, АнП и МПК/МАМ.

Добавлено в API:

- `POST /measurements/{measurement_id}/thresholds`;
- `GET /measurements/{measurement_id}/thresholds`;
- `GET /measurements/{measurement_id}/zones`.

Добавлено в frontend:

- выбор строки таблицы;
- кнопки назначения порогов;
- селектор физиологической точки в таблице;
- блок тренировочных зон.
