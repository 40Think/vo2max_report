# VO2max / MPK Report: отчет по фазам 0-2

Дата: 2026-04-29

Этот документ фиксирует, что уже сделано в первой технической итерации продукта.

## Что реализовано

### Phase 0. Подготовка проекта

Создана рабочая структура будущего веб-приложения:

- `backend` - серверная логика;
- `frontend` - место для будущего интерфейса;
- `docs` - технические заметки по реализации;
- `samples` - обезличенные тестовые файлы;
- `storage/raw_files` - локальное хранилище исходных файлов приборов;
- `storage/reports` - место для будущих отчетов.

Добавлен `.gitignore`, который исключает локальные базы, кэш, окружения, `node_modules`, raw files и сгенерированные отчеты.

### Phase 1. Backend core и модель данных

Добавлены базовые доменные модели:

- клиент;
- тест/измерение;
- строка измерения;
- физиологические пороги;
- исходный файл;
- audit trail для будущей истории ручных правок;
- предупреждения импорта.

Модель строки измерения покрывает ключевые поля из старой C# программы: время, VO2, ЧСС, мощность, дыхательные показатели, каденс, температура, влажность и служебные признаки качества.

### Phase 2. Импорт legacy CSV

Реализован импорт исходного CSV-формата из старой программы:

- распознавание legacy CSV;
- нормализация чисел с десятичной запятой;
- маппинг колонок прибора в внутренние поля системы;
- import preview;
- список распознанных полей;
- список проигнорированных колонок;
- предупреждения по проблемным строкам;
- сохранение исходного файла в raw storage;
- базовый расчет `StartPower`, `PowerStep` и `RatedPower`.
