## Демо-путь

1. Создать клиента.
2. Выбрать legacy CSV-файл или указать локальный путь к legacy CSV.
3. Загрузить/импортировать тест.
4. Убедиться, что таблица измерений заполнена.
5. Изменить значение в одной из ячеек.
6. Назначить пороги из выбранных строк: АэП, АнП, МПК/МАМ.
7. Проверить, что графики отображают реальные данные.
8. Проверить, что выбранная строка подсвечивается на графиках.
9. Проверить блок тренировочных зон.
10. Открыть предпросмотр отчета.
11. Сгенерировать HTML, PDF и DOCX.
12. Скачать созданные файлы отчета.
13. При наличии нескольких тестов проверить сравнительный блок в отчете.

## Ожидаемый результат

Специалист проходит путь:

```text
клиент -> CSV upload/import -> таблица -> правки -> графики -> пороги -> зоны -> сравнение -> HTML/PDF/DOCX отчет
```

Если этот путь проходит без ручной подготовки CSV и без падений приложения, фазы 0-9 MVP считаются закрытыми.
