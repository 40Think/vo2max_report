# VO2max / MPK Report: отчет по фазам 3-4

Дата: 2026-04-29

Этот документ фиксирует, что добавлено после технического фундамента фаз 0-2.

## Phase 3. Клиенты и история тестов

Добавлен слой приложения для работы со специалистом, клиентами и тестами:

- file-backed repository для локального сохранения состояния между запусками;
- создание клиента;
- обновление клиента;
- поиск клиента по ФИО, телефону и email;
- карточка клиента;
- история тестов клиента;
- импорт legacy CSV сразу в историю конкретного клиента;
- привязка исходного raw file к тесту;
- audit event при импорте теста.
- application API для сценариев клиента, тестов и импорта.
- минимальный HTTP server на стандартной библиотеке Python.

Главная идея фазы: система начинает работать не с абстрактным CSV-файлом, а с конкретным клиентом и его историей диагностики.

## Phase 4. Главный рабочий экран теста

Добавлено ядро и минимальный browser UI рабочего экрана, близкого по логике к старой C# программе:

- получение workspace для клиента и активного теста;
- активный тест;
- история тестов клиента;
- таблица строк измерений;
- редактирование любой ячейки строки измерения;
- включение/исключение строки из отчета;
- выбор каждой N-й строки для сглаживания/агрегации;
- ручная установка `StartPower` и `PowerStep`;
- автоматический пересчет `RatedPower`;
- audit trail для ручных правок;
- frontend-ready view model для будущего интерфейса.
- статическая страница `frontend/index.html`;
- редактируемая таблица измерений в браузере;
- запуск локального приложения через `python -m vo2max.api.server`.

Подготовлена структура таблицы для frontend:

- видимость строки в отчете;
- время;
- расчетная мощность;
- фактическая мощность;
- ЧСС;
- VO2;
- дыхательные показатели;
- каденс;
- лактат;
- физиологическая точка.
